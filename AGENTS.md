# AGENTS.md

## What this repo is
A free library of ~30 clay-style avatars (PNG, WebP, looping MP4) published as an npm package, with a one-page static site in `site/`. Premium packs come later and are NOT in this repo's free set.

## Source of truth
- `avatars.json`: one entry per avatar (id, name, mood, role, age, tags, alt). Edit this, never the generated files.
- `project.config.json`: name, display name, GitHub repo, tag.- `assets/{png,webp,mp4}/<id>.<ext>`: file names must match the avatar id.
- `provenance/<id>.json`: model, prompt, seed and edit notes for each avatar. Keep these. Gitignored (private, never committed or published); only `provenance/README.md` is tracked.

## Generated (do not edit by hand)
`packages/clayfolk/manifest.js`, `packages/clayfolk/assets/`, `llms.txt`, `site/avatars.json`. Run `pnpm build:manifest`.

## Commands
- `pnpm build:manifest`: validate avatars.json and regenerate everything.
- `pnpm test`: run the library API tests (`packages/clayfolk/test/`).
- `pnpm check:sizes`: fail if what the package bundles (webp + cutout + mp4, 15 MB) or the MP4 set alone (10 MB) exceeds the size budget.
- `pnpm encode:videos [id ...]`: encode `masters/mp4/` into `assets/mp4/`.

## Rules
- The npm package bundles WebP (`assets/webp`, `assets/webp-cutout`) and the MP4 loops (`assets/mp4`). PNGs (`assets/png`, `assets/png-cutout`) are NOT in the package; they are site downloads only (site/assets and clayfolk.zip). All URLs from `imageUrl`/`videoUrl` use the jsDelivr npm CDN, so nothing depends on a pushed git tag.
- Videos: raw fal masters live in `masters/mp4/` (gitignored, back up separately). Only the encoded loops in `assets/mp4/` are committed. Make them with `pnpm encode:videos` (720px, CRF 23, BT.601 to BT.709 color conversion and tags, all 60 frames kept; needs ffmpeg). Never commit the masters.
- Every avatar needs an `alt` string.
- The site must not hardcode the pack size. The pack can grow (38, 56, ...) with no front-end change: no counts in copy, no fixed grid slots or loop lengths, filters and chips derived from `site/avatars.json`. Show a count only when rendered from `avatars.length`. Test the page with the list cut to 8 and padded to 56.
- Cutouts (`assets/png-cutout/`, `assets/webp-cutout/`) are generated by Codex (ChatGPT image generation) from the 1024px source stills; regenerated images, not pixel extractions. Masters (1024px) live in `masters/cutout-1024/` (gitignored); 512px staging in `masters/cutout-512/`. Cutout prompt and notes are in each `provenance/<id>.json`.
- Don't add dependencies without a reason. The package has zero runtime dependencies.
- Do not publish to npm or push tags without the owner's say-so.

## Site build
`pnpm build` also runs `scripts/build-site.mjs`, which copies images into `site/assets/` (`cutout/` from `assets/webp-cutout/`, plus `webp/`, `png/`), writes `site/assets/features.json` (`mp4: true` once `assets/mp4/` has files), `site/llms.txt` and `site/clayfolk.zip`. All of these are gitignored. `assets/webp-cutout/` (transparent, 512px WebP) is bundled in the npm package (`imageUrl(id, { variant: "cutout" })`); `assets/png-cutout/` is site-download only. Fonts are self-hosted in `site/fonts/` (Geist, OFL). Site config (hero id, word list, waitlist endpoint) lives at the top of `site/app.js`.
